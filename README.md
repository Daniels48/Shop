# Shop 

Shop — настольное приложение для автоматизации работы магазина, управления товарами, учёта продаж и контроля складских операций.

Приложение позволяет вести каталог товаров, обрабатывать продажи, учитывать различные
способы оплаты, отслеживать изменения остатков и просматривать статистику работы магазина.

В проекте реализовано взаимодействие с банковским POS-терминалом. Для работы интеграции требуется дополнительное программное обеспечение и компоненты, предоставляемые банком. Эти файлы не включены в репозиторий из-за ограничений.

## Возможности
- Управление товарами и их характеристиками
- Учёт штрихкодов товаров
- Поиск товаров по штрихкоду
- Оформление продаж
- Поддержка оплаты наличными, банковской картой и комбинированной оплаты
- Учёт продаж и способов оплаты
- Управление складскими остатками
- Добавление и списание товаров
- Создание и объединение товарных позиций
- История изменений товаров и складских операций
- Просмотр статистики продаж за день и месяц
- Учёт выручки и количества проданных товаров
- Учёт обедов и дополнительных операций
- Интеграция с банковским POS-терминалом через спец ПО

## Запуск проекта

### 1️⃣ Клонировать репозиторий

```bash
git clone https://github.com/Daniels48/Shop.git
```
```bash
cd Shop
```


### 2️⃣ Создать файл `.env`

Скопируйте `.env.example` и переименуйте его в `.env`:

```bash
cp .env.example .env
```

После этого при необходимости измените значения переменных в файле `.env`.

### 3️⃣ Создание виртуального окружения

Создай виртуальное окружение Python:
```bash
python3 -m venv venv
```
Активируй его:

**Linux / macOS:**

```bash
source venv/bin/activate
```

**Windows :**

```bash
.\venv\Scripts\Activate
```

### 4️⃣ Установка зависимостей
Установи зависимости проекта:
```bash
pip install -r requirements.txt
```


### 5️⃣ Запуск PostgreSQL

```bash
docker compose up -d --build
```

### 6️⃣ Применить миграции
```bash
alembic upgrade head
```

### 7️⃣ Сборка приложения
Сборка выполняется с помощью PyInstaller.
```bash
pyinstaller --clean Shop.spec
```
